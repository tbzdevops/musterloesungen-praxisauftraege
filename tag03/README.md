# Tag 03 – Praxis-Musterlösungen

MVP und User Stories: Die Praxis-Aufträge behandeln das iterative Aufteilen grosser Features in
lieferbare MVP-Schritte und das Formulieren von Epics und User Stories nach dem INVEST-Prinzip.
Als Fallbeispiel dient das Feature **Full Self Driving (FSD) für LKWs**.

Die beiden Lösungen sind **aufeinander abgestimmt**: Die Epics und User Stories in Auftrag 2
bauen direkt auf den MVP-Phasen aus Auftrag 1 auf.
