# Tag 01 – Praxis-Musterlösungen

Einführung in DevOps: Die Praxis-Aufträge sind **Gruppenarbeiten** zu den drei zentralen
Denkmodellen CALMS, The Three Ways und den DORA-Metriken. Die Klasse teilt sich in **drei
Gruppen** – jede analysiert denselben Betrieb (**TechStyle**) durch eine andere Brille. Jede Lösung
enthält den passenden **Theorie-Block** plus eine ausgearbeitete Beispiel-Lösung der Gruppenarbeit
zum konkreten Szenario.
